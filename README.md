# Portafolio

Mi portafolio personal. Está hecho con HTML y Tailwind (por CDN), sin build
ni frameworks. El único JavaScript que tiene es el menú del celular.

## Archivos

- `index.html` — todo el contenido y las clases de Tailwind
- `script.js` — abrir/cerrar el menú en pantallas chicas
- `assets/perfil.jpg` — foto de perfil

## Notas

Los colores están definidos en `tailwind.config` dentro del HTML (fondo,
panel, borde, verde, dorado) para no repetir códigos hexadecimales por todos
lados.

Para verlo: abrir `index.html` en el navegador.
